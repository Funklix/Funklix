# Dashboard 2.0 Product Spec

## Mission Control

---

# Vision

The Dashboard is not a homepage.

It is not a collection of widgets.

It is not a reporting screen.

The Dashboard is the first conversation between the user and their Brand.

Its purpose is simple:

**Before the user asks "What should I do today?", Funklix should already have the answer.**

The Dashboard exists to reduce complexity into clarity.

Every element shown should help the user understand where their attention creates the greatest impact.

If something is not actionable, it does not belong on the Dashboard.

---

# Product Philosophy

Traditional dashboards answer:

> What happened?

Funklix answers:

> What deserves my attention today?

This distinction defines the entire experience.

The Dashboard is not the place where work happens.

It is where priorities become obvious.

---

# The Daily Briefing

Every morning the Dashboard delivers a short, curated briefing.

Never overwhelming.

Never noisy.

Never filled with unnecessary metrics.

The briefing should feel like arriving at work and having an experienced strategist already waiting with everything prepared.

Its purpose is to create clarity before action.

---

# The Brand Avatar

The Brand Avatar is the centerpiece of the Dashboard.

It is not an assistant.

It is not ChatGPT.

It is the Brand itself.

The Brand speaks in first person.

Examples:

> "Good morning Felix. I discovered a new positioning opportunity after comparing our messaging with three competitors."

> "I think our Founder Story could create more trust in our landing page."

> "I noticed that visionary messaging consistently performs better than technical messaging."

The Brand never orders.

The Brand never criticizes.

The Brand collaborates.

It prepares.

It observes.

It suggests.

---

# Continue Working

The most important card on the Dashboard.

Not Recent Boards.

Not All Projects.

One recommendation.

The campaign that deserves attention now.

It should answer:

* What is the current status?
* Why is this campaign important today?
* What changed since yesterday?
* What should happen next?

One click returns the user exactly where they left off.

---

# Brand Intelligence

The Dashboard should never display a generic "Health Score."

Instead it should show the evolution of the Brand.

Examples:

Brand Intelligence

* Completeness
* New Knowledge
* Suggested Improvement

The emphasis is not on percentages.

It is on progress.

The user should feel their Brand is becoming smarter over time.

---

# Suggested Opportunities

The Dashboard should inspire.

Never overwhelm.

Suggestions are opportunities, not warnings.

Examples:

* Explore a Founder-led campaign.
* Test a new positioning angle.
* Review an overlooked ICP segment.
* Expand the Founder Story.
* Import competitor research.

The tone is optimistic.

The AI is a strategic sparring partner.

Never a critic.

---

# Today's Focus

Tasks are not a separate system.

Tasks are Nodes that require attention.

Every unfinished node assigned to a user automatically becomes part of Today's Focus.

Only the most relevant items are shown.

The Dashboard answers:

What are the next three meaningful actions?

Nothing more.

---

# Live Campaigns

If campaigns are deployed, the Dashboard provides a lightweight overview.

Planning

Running

Learning

Completed

Detailed analytics belong to Insights.

The Dashboard only provides orientation.

---

# Team Activity

The Dashboard surfaces meaningful collaboration.

Examples:

* Campaign reviewed.
* Asset approved.
* AI suggestion accepted.
* Founder Story updated.

Only relevant activity appears.

Noise is removed.

---

# Learning

Every completed campaign should make the Brand Brain better.

The Dashboard therefore celebrates learning, not only execution.

Examples:

> "Your Brand became more consistent."

> "Your ICP definition is becoming more specific."

> "Customers consistently respond better to visionary messaging."

Campaigns finish.

Learning continues.

---

# Brand Evolution

The Brand is never static.

Every campaign changes the Brand.

Every insight enriches the Brand Brain.

Every approved improvement becomes permanent knowledge.

The Dashboard should make this evolution visible.

Not through scores.

Through stories.

---

# Information Hierarchy

The Dashboard follows one question:

What should the user know before they begin working?

Priority:

1. Daily Briefing
2. Continue Working
3. Brand Intelligence
4. Suggested Opportunities
5. Today's Focus
6. Live Campaigns
7. Team Activity

Everything else belongs elsewhere.

---

# Relationship to Other Product Areas

Dashboard

Shows priorities.

AI Brain

Explains recommendations.

Campaign Canvas

Executes work.

Insights

Measures outcomes.

Simulation

Explores possibilities.

Brand Brain

Stores truth.

The Dashboard owns nothing.

It only orchestrates attention.

---

# Product Principles

The Dashboard never overwhelms.

The Dashboard always prioritizes.

The Dashboard never duplicates information.

The Dashboard celebrates learning.

The Dashboard helps the user decide, not explore.

The Dashboard is optimistic.

The Dashboard reduces complexity.

The Dashboard is the daily briefing of the Marketing Operating System.

---

# Long-Term Vision

Eventually, opening Funklix should feel less like opening software and more like walking into a strategy meeting where the Brand has already prepared everything worth discussing.

The user does not start with dashboards.

The user starts with clarity.

And from that clarity, great marketing decisions become easier every day.
