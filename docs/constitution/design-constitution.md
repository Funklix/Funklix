# Funklix Design Constitution

## Purpose

This document defines the design philosophy of Funklix.

Its goal is not to prescribe pixel-perfect interfaces, but to ensure
every screen feels like it belongs to the same product.

Consistency is a feature.

------------------------------------------------------------------------

# Core Design Principles

## Calm before Complex

Marketing is already complex.

The interface should reduce cognitive load instead of adding to it.

Users should always know where they are, what they are doing and what
comes next.

------------------------------------------------------------------------

## AI Should Feel Collaborative

AI is not represented as an anonymous machine.

It should feel like a trusted teammate working alongside the user.

AI interactions should encourage confidence, curiosity and
collaboration.

------------------------------------------------------------------------

## Explain the Work

Whenever AI performs a meaningful task, the product should communicate
progress.

Users should never wonder whether something is happening.

Loading states should educate, reassure and build anticipation.

------------------------------------------------------------------------

## Premium, Not Playful

Funklix should feel modern, confident and premium.

Small moments of delight are encouraged, but they should never undermine
trust.

Avoid gimmicks.

Prefer subtle polish.

------------------------------------------------------------------------

## Motion Has Purpose

Animations should:

-   explain state changes
-   reinforce hierarchy
-   guide attention
-   reduce perceived waiting time

Animation should never exist only for decoration.

------------------------------------------------------------------------

# Visual Language

The visual language should communicate:

-   clarity
-   intelligence
-   creativity
-   confidence
-   craftsmanship

Avoid visual noise.

Whitespace is part of the design.

------------------------------------------------------------------------

# Components

Every component should have one recognizable style across the product.

This includes:

-   Buttons
-   Cards
-   Inputs
-   Dialogs
-   Sidebars
-   Navigation
-   Badges
-   Progress Indicators
-   Empty States
-   Notifications

Default browser styling should never appear in production.

------------------------------------------------------------------------

# Typography

Typography should create a clear hierarchy.

One font family should be used consistently unless there is a compelling
reason otherwise.

Avoid mixing styles that make the interface feel assembled from multiple
products.

------------------------------------------------------------------------

# Colors

Colors communicate meaning.

Primary colors establish identity.

Neutral colors provide structure.

Semantic colors communicate status.

Green should represent success.

Yellow should represent attention.

Red should represent errors.

Color should support understanding, never decoration alone.

------------------------------------------------------------------------

# Dashboard Philosophy

The Home Dashboard should answer three questions within seconds:

-   Where should I continue?
-   What changed?
-   What deserves my attention?

The dashboard orchestrates work.

It should never become another workspace.

------------------------------------------------------------------------

# AI Experiences

Every major AI interaction should feel intentional.

Examples include:

-   Campaign Generation
-   Brand Analysis
-   AI Brain Conversations
-   Simulations

AI moments should create confidence, not uncertainty.

Completion should feel rewarding.

------------------------------------------------------------------------

# Accessibility

Design decisions should prioritize readability, contrast and usability.

Beautiful interfaces that reduce usability are considered failures.

------------------------------------------------------------------------

# Future Design System

A shared design system will define:

-   spacing
-   typography scales
-   color tokens
-   iconography
-   elevation
-   radii
-   motion tokens
-   component library

Every new interface should extend this system instead of creating
isolated styles.

------------------------------------------------------------------------

# Decision Checklist

Before introducing a new UI ask:

1.  Does it feel like Funklix?
2.  Does it reduce cognitive load?
3.  Does it strengthen consistency?
4.  Does motion have a purpose?
5.  Does AI feel collaborative?
6.  Would this scale across the product?

If several answers are "No", redesign before implementation.

------------------------------------------------------------------------

# Closing Principle

Great design should make sophisticated marketing feel approachable.

The best interfaces disappear behind the user's creativity.
