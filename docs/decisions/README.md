# Decisions

Architecture Decision Records (ADRs) document product, architecture, or engineering decisions that affect future work.

## ADR Usage

- Use ADRs for product, architecture, or engineering decisions that affect future work.
- ADRs should be short, dated, and explicit.
- ADRs should explain why a decision was made, not just what changed.
- ADRs should link to related audits or feature specs when relevant.
