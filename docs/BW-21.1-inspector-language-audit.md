# BW-21.1 Campaign Canvas Inspector language audit

## Rendering paths and active surface

The Inspector is a single persistent `#inspector-panel` / `#node-form`; `fillInspector` renders either the empty state or the selected node. Its base sections are **Basic**, **Images**, **Strategy**, **AI Actions**, **Node Actions**, and **Connected Context**. Conditional paths expose Social fields for `Social Media Posting`, upload/prompt/format controls for `Content`, landing-page copy and header-visual controls for `Landing Page`, posting schedule feedback for social nodes, image empty/list/action states, multi-selection delete/disconnect states, and the review-driven AI Workspace.

The audited system surface includes the heading and selection/editing messages; type/status/owner selectors; title/content/image prompt fields; landing-page labels, placeholders, and generation action; platform, caption, hashtag, audience, goal, channel, funnel, tone, and variant fields; image generation/upload/favorite/download/delete controls and accessible names; AI improvement/review/regeneration/full-pack actions and AI Workspace loading/error/apply/dismiss labels; schedule feedback; node deletion/disconnection/propagation actions; and parent/child collapsed summary plus expanded labels.

## Translation lifecycle and DOM contract

BW-21 provides dependency-free `language.js` preferences, an English-canonical `t()` fallback, declarative `data-i18n`/`data-i18n-placeholder` updates, and the Utilities language change listener in `app.js`. BW-21.1 extends that dictionary and applies translations to the existing Inspector IDs without replacing the form or registering another form/language handler. System select options receive translated display text through `data-i18n`, while their `value` attributes remain canonical.

On an Interface-language change, `refreshOpenInspectorLanguage()` updates the open Inspector's system text and dynamic render-only regions. It does not assign form values, dispatch events, change selection, call Canvas persistence, mark dirty, or invoke autosave. Re-rendered image/AI children replace their prior children, so repeated switches cannot accumulate controls or handlers.

## System text versus Board content

Translated values are system-owned labels, headings, placeholders, actions, tooltips, accessibility names, status/type/strategy option labels, and feedback shells. Canonical node-type/status/strategy values are not changed. Node titles and content, captions, hashtags, prompts, landing-page copy, comments/replies, generated review/campaign copy, image names, URLs, Board/Brand names, member names/emails, IDs, JSON keys, and schema fields remain verbatim. Parent/child titles, owner identities, dates/times, and AI-provided text are inserted with safe text nodes inside translated system labels.

## Existing coverage

The pre-existing BW-21 check covers language preference separation, persistence, safe fallback, generation-language capture, and browser script compatibility. The focused BW-21.1 check adds Inspector key completeness, every conditional path, canonical enum preservation, immediate open-Inspector refresh, user-content boundaries, state/persistence exclusions, single-handler behavior, workflow ordering, and compatibility assertions.
