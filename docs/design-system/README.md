# Design System

This folder documents the design-system direction for Funklix. It is documentation only and does not implement CSS, runtime behavior, routes, or design tokens yet.

## Direction

The design foundation should define and evolve through documented patterns before broad implementation:

- **Design tokens** — shared values for color, spacing, typography, radius, elevation, and related primitives.
- **Button system** — consistent button hierarchy, sizing, states, and interaction expectations.
- **Card system** — reusable card structure for product surfaces and content groupings.
- **Badges/status states** — consistent visual language for labels, health, progress, warnings, and outcomes.
- **Modal patterns** — predictable modal structure, focus behavior, hierarchy, and dismissal expectations.
- **Motion principles** — restrained, purposeful motion that supports clarity without distracting from work.

Dashboard should be the first consumer of the design foundation.
