# Required delivery workflow

For every implementation task in this repository:

1. Work on a dedicated branch.
2. Commit and push the completed work.
3. Create exactly one normal, non-draft pull request against `main`.
4. If the platform creates a draft automatically, immediately mark it ready for review.
5. Verify the final pull request has `draft: false`.
6. Return the real GitHub pull-request URL.
7. A branch or commit without a normal pull request is not a completed delivery.
8. Never merge the pull request.
9. If pull-request creation is technically impossible, report `BLOCKED`. Do not claim `READY`, do not invent a URL, and do not silently change the workflow.
